# 보안 관리 팁

- 솔직히 개인이 쓸수 있는 리눅스용 백신이 거의 없기에 주로 clamav를 많이 설치 할텐데 좀더 편하게 쓸수 있는 방법에 대해 정리해보려고 한다.
- clam UI 라는 프로그램 인데 clam av를 gui로 제어하면서 나름 개인들이 쓸만한 프로그램이다.
- opensnitch 는 네트워크 감시 도구인데 요즘처럼 공급망 공격이 심할때 쓰다가 갑자기 이상한데로 프로그램이 ip로 접근하면 바로 경고를 사용자에게 알리기에 쓸만한 도구.


#### 실시간 검사 설정

 `sudo nano /etc/clamav/clamd.conf`

```bash

# 1. 감시할 경로 지정
OnAccessIncludePath /home/ssh1032007

# 2. 무한 루프 방지 (clamd 프로세스 제외)
OnAccessExcludeUname clamav

# 3. 바이러스 발견 시 즉시 차단 (선택 사항, 권장)
OnAccessPrevention yes

# 4. tmp 추가 
OnAccessIncludePath /tmp
```

`sudo systemctl restart clamav-daemon`
