# Project SonarValidator

- 3학년이 되면서 학교에서 과제로 프로젝트를 하나 만들어야 했는데, 평소에 보안이랑 인프라에 관심이 매우 많았기에, 이 점을 활용해서 네트워크 보안을 관리하는 솔루션을 하나 만들게 되었다.

## 프로젝트 아이디어와 설계

- 여러 네트워크 솔루션들이 있는데 굳이 이렇게 또 만드는 데에는 뭔가 이유가 있어야 할 것 같아서 생각해보니, 내가 아직 취업해서 SIEM(Security Information and Event Management)라고 해서 보안 관련해서 로그 분석하고 막 알려주는 여러 솔루션들을 다루어 보지는 않았지만, 나 나름대로 이게 만약에 회사나 기관에 있으면 좀 도움이 되지 않을까라는 생각이 들어 이 아이디어로 플젝을 하게 되었다.
- 내 프로젝트는 전형적인 Client-Server 구조로 네트워크 장비들을 알아보니 Arista나 Cisco 같은 회사들이 리눅스 커널 기반으로 만들거나 아예 LXC 컨테이너를 기반으로 네트워크 장비 운영체제를 구축한다는 점 덕분에 그러면 얘들 API로도 제어 하긴 하는데 회사들이 API로 완전히 제어가 안될 수도 있고 또 RESTCONF 등등의 표준이 있긴한데 제대로 호환이 100%로 되는 건 아니라고 들어서 Agent를 하나 만들어서 장비들에 설치시키면 편하게 제어 하지 않을까 하는 아이디어에서 프로젝트를 시작하게 되었다.

## 프로젝트 구현

- 군 제대 후에 대 바이브 코딩의(?) 시대가 오면서 순수 개발자가 작성하는 코드보다 인공지능이 쓰는 코드가 많아지기는 했는데 일단 내가 설계를 한다음에 최대한 내가 코드 처보고 안되는 부분이 있으면 인공지능을 돌릴 예정이다 물론 프로젝트하면서 처음 써보는 라이브러리도 있고, 멀티 스레드를 써야하기에 일단 문서 보고 최대한 한 다음에 내가 모르는게 있으면 AI 돌려가면서 코딩 할 것 같다.
